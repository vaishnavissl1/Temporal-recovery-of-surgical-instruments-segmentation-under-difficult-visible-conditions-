Simplification, stated: A4 is applied on frames the gate flags (reliability < 0.64) as a rule that fires or does not; it is not a learned-selector candidate, because that would need the selector's per-action features, which require the full action pipeline (hours of CPU). "Gated like any other action" is implemented as "applied on flagged frames only".
